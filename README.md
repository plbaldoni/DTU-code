# DTU-code

This website hosts code for the paper "Dividing out quantification uncertainty enables assessment of differential transcript usage with limma and edgeR" by Baldoni et al. (2025), which presents optimized differential transcript usage pipelines using the latest versions of the R/Bioconductor packages [edgeR](https://bioconductor.org/packages/release/bioc/html/edgeR.html) and [limma](https://bioconductor.org/packages/release/bioc/html/limma.html). 

The bioRxiv preprint version of the paper can be accessed from: https://doi.org/10.1101/2025.04.07.647659

The analysis website can be found at the following link: https://plbaldoni.github.io/DTU-code
